# Engineering Learning Lab

## About This Repository

This repository documents my journey learning programming, computer science, electronics, and engineering through hands-on projects.

Rather than focusing entirely on tutorials, my goal is to build projects independently, develop problem-solving skills, and gradually take on more complex technical challenges.

Projects range from small Python programs to future work involving electronics, microcontrollers, CAD, mechanical design, and hardware.

## Learning Goals

- Strengthen my programming skills in Python, Java, and other languages.
- Learn to design, build, test, and debug software independently.
- Explore electronics, circuits, microcontrollers, and mechanical systems.
- Develop CAD and hardware prototyping skills.
- Apply mathematics, probability, and statistics to real-world projects.
- Learn proper documentation, testing, and version control.

## Long-Term Projects

One of my primary goals is to develop a poker statistics and opponent analysis system that uses historical game data to identify patterns in player behavior.

I am also interested in creating projects that combine software with physical hardware, such as sensor-based devices, servo-controlled mechanisms, and custom-designed components.

These larger projects will be developed as I build the necessary skills through smaller experiments.

## Development Process

For each project, I aim to:

1. Define the objective and technical requirements.
2. Design and implement a solution.
3. Test the project against expected behaviors.
4. Debug and improve the implementation.
5. Document what I built and learned.

## Repository Purpose

This repository is primarily a record of my technical development. Early projects are intentionally simple, with the goal of progressing toward more challenging and original engineering work over time.
