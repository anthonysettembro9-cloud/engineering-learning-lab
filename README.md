# Project 001: Number Guessibng Game

## Description:
A python guessing game where a user guesses a number between 1 to 100.

## Features:
Random number generator
While loops
Try/except
ValueError
Break
Continue
Input

## How to Run:
Runs via ternimal, with "python3 main.py

## How it Works:
Generates a number 1-100, and user attempts to guess it in as few attempts as possible. The game keeps track of how many attempts it takes you. The ternimal will inform you if your guess it too high or low, or if you guess is invalid.
