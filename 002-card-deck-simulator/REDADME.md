
# Card Deck Simulator

## Overview
A Python program that generates a standard 52-card deck and randomly deals a two-card hand without replacement.

## Features
- Generates 52 unique playing cards
- Randomly selects two cards
- Removes selected cards from the deck
- Prevents duplicate cards
- Validates user input
- Organizes code into reusable functions

## Concepts Learned
- Lists and list manipulation
- Nested for loops
- Functions
- Parameters and arguments
- Return values
- Local variable scope
- Random selection without replacement

## How to Run

Run the following command from the project directory:

```bash
python3 main.py
```

Press Enter to receive your two cards.

## Example Output

```text
Press enter to see your two cards:
['Queen of Clubs', '10 of Clubs']
```
